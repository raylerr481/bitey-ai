# Bitey AI 2.1.0 — WordPress ZIP

Use the repository **Code → Download ZIP** to download this plugin for WordPress.

The ZIP must have the plugin directory `bitey-ai/` at its root and contain `bitey-ai.php`, `includes/`, and `assets/`.

Version: 2.1.0

Features: Bitey floating AI widget, ES/PT-BR/EN language selector with automatic detection mode, progressive customer identification, persistent customer/conversation context, quick service actions, and governed Bitey Backend integration.
