Bitey AI WordPress Plugin 2.0

Bitey is the WordPress channel client for the Bitey AI enterprise core.

Architecture
- WordPress plugin: widget, channel state, tenant/channel configuration and secure AJAX bridge.
- Bitey Core API: business intelligence, language detection, knowledge, intent, decisioning, workflows, CRM, tickets and memory.
- WordPress must not contain enterprise reasoning or business rules that belong in the Core.

Features
- PT-BR, Spanish and English.
- Explicit language preference or automatic detection by the Core.
- Persistent conversation ID in the browser.
- Company/Tenant ID.
- Secure WordPress AJAX nonce.
- Backend health diagnostic endpoint.
- Responsive chat widget.

Configuration
WordPress Admin -> Settings -> Bitey AI

Default backend:
https://bitefixes-backend.onrender.com

Version: 2.0.0
